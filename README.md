## 🚀 Featured Projects

### [OpenUSD Reactive Simulation-On-Demand](https://github.com/pahujashreya5/OpenUSD-reactive-simulation-on-demand-project)
A Python-based USD pipeline that detects geometry collisions via AABB bounding boxes to trigger external simulations. It integrates headless Houdini (hython) via OS subprocesses to procedurally generate and bake VEX-driven particle effects, mapping payloads back into the master scene graph to maintain interactive viewports.

### Algorithmic Design in Computational Geometry
Translated complex academic research concepts into efficient Houdini VEX implementations. Developed custom computational geometry solutions including k-d trees, spatial hashing, Laplacian mesh solvers, and shape matching via Horn's quaternions method.

### USD Cloud Streaming Pipeline *(WIP)*
Designing a streaming architecture utilizing NeuralGS decoding for remote execution and transmission of USD payload data.
